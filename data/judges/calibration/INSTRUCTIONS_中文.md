# 评分者说明 — 评判器校准研究（中文版）

您将为环境健康科学领域开放式问题的回答打分。`human_rating_sheet.csv` 的每一行包含一道题目（QUESTION）、一个参考（金标）答案（GOLD_ANSWER）和一份匿名化的回答（ANSWER_TEXT）。这些回答来自若干个 AI 系统，但系统身份已被隐去、行序已被打乱——请**不要**猜测某份回答出自哪个系统，只依据文本本身的质量打分。

**注意：题目与答案保持英文原文。** 本基准是英文基准，被评的就是英文回答本身，因此表格内容不做翻译；仅说明文件提供中文。

## 您的任务

对每一行，阅读 QUESTION、GOLD_ANSWER 与 ANSWER_TEXT，然后在您自己的列（`rater1_score_0_5` 或 `rater2_score_0_5`）中填入 0 到 5 的整数分。两位评分者必须**独立**完成——在两列都填完之前，不要讨论任何一行。

## 评分标准（请严格使用此量表）

以参考答案为基准，在 0 到 5 分上为该回答打分。

- **5 分**：完全正确，覆盖全部要点，细节准确。
- **4 分**：基本正确，有少量遗漏或轻微不精确。
- **3 分**：部分正确，抓住主旨但遗漏重要细节。
- **2 分**：较弱，显示出一定理解，但有明显缺口或部分错误。
- **1 分**：大体错误，仅与题目勉强相关。
- **0 分**：完全错误、答非所问，或没有实质回答。

（此量表与自动 LLM 评判器所用的量表逐字一致，因此人工分数与机器分数可以直接比较。）

## 基本规则

1. 以 GOLD_ANSWER 为基准打分，而不是以您自己偏好的答案为基准。如果回答经由不同但有效的路径得到金标结果，同样算对。
2. 数值型回答：与金标值相差约 5% 以内（或经一次明显的单位换算后正确）视为正确；数量级错误属于重大错误。
3. 空白、回避或跑题的 ANSWER_TEXT 记 0 分。
4. 超出金标答案的额外**正确**细节不扣分；额外的**错误**论断要扣分。
5. 只填整数（0、1、2、3、4、5），不要留空。
6. 请勿打开 `blinding_key.json` 或 `judge_inputs.jsonl`——它们会揭示每份回答出自哪个系统，从而破坏盲评。

两列全部填完后，请把 CSV 交回研究协调人，由其运行 `analyze_agreement.py` 计算一致性统计。
