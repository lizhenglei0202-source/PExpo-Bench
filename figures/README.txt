Figure files and their numbering in the paper
=============================================
The filenames below predate the final SI figure ordering. The paper's numbering is
authoritative; build_docx.py maps each file to its correct caption.

MAIN TEXT
  Figure_1_arch_mechanism.png            -> Figure 1  (architecture design space)
  Figure_2_results.png                   -> Figure 2  (accuracy, sub-domain, cost)
  Figure_3_environment_effect.png        -> Figure 3  (original vs corrected exhibit)
  Figure_4_reliability_diagnostics.png   -> Figure 4  (IF, coverage, contradiction)
  Figure_5_configuration_contrast.png    -> Figure 5  (A4 vs A3 contrasts)

SUPPLEMENTARY  (note: filename number != SI figure number)
  Figure_S2_efficiency_robustness.png    -> SI Figure S1 (efficiency x robustness)
  Figure_S3_factorial.png                -> SI Figure S2 (factorial decomposition)
  Figure_S1_difficulty_taxonomy.png      -> SI Figure S3 (difficulty taxonomy)

Underlying values for every panel: PExpo-Bench_figure_data_v4.xlsx
